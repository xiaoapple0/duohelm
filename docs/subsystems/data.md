# 行情与数据

## 职责

- 行情源插件：从外部数据源取数，转换成标准格式
- 平台：校验格式和质量、入库、提供给因子计算和回测

## 标准格式

权威定义：`packages/duohelm-sdk/src/duohelm_sdk/schema.py`。

日频 K 线（`BARS_SCHEMA`）：

| 列 | 类型 | 说明 |
|---|---|---|
| `date` | Date | 交易日 |
| `symbol` | String | 证券代码，A 股用 `600000.SH` / `000001.SZ` / `430047.BJ` 格式 |
| `open` `high` `low` `close` | Float64 | **未复权**价格 |
| `volume` | Float64 | 成交量（股） |
| `amount` | Float64 | 成交额（元） |

复权因子单独存储，在计算时按需应用。原因：前复权价格会随新的除权事件改变历史值，直接存前复权价格会破坏可复现性，也容易引入未来函数。

## 存储（M1）

- 行情和因子值：Parquet，按 `freq=<频率>/year=<年>` 分区，用 DuckDB 或 polars 查询
- 元数据（股票池、插件状态、任务）：SQLite
- 数据根目录：`$DUOHELM_HOME`，默认 `~/.duohelm`

## Point-in-time 要求

| 数据 | 必须按什么时间对齐 |
|---|---|
| 复权因子 | 除权除息日 |
| 指数成分股 | 调入、调出生效日 |
| 财务数据 | 公告日，不是报告期 |
| 行业分类 | 分类变更生效日 |
| ST 标记 | 实施日 |

## 已知缺口

- M0 只定义了格式，没有实现入库和质量检查
