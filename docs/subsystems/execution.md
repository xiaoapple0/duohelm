# 交易执行（M6 起实现）

本子系统的任何代码改动都**只能由维护者合并**，不允许 agent 自动合并。

## 分层

```
策略信号
   │
   ▼
平台风控层（平台实现，插件绕不过去）
   │  单笔上限 / 单日上限 / 单票持仓上限 / 价格偏离 / 紧急停止
   ▼
交易接口插件（BrokerPlugin）
   │
   ▼
券商（模拟盘 / 实盘）
```

## 要求

- **风控在平台层**：所有委托先经过平台风控检查，再调用插件。插件不能直接收到未检查的委托
- **紧急停止**：页面上一键停止所有自动交易，停止后拒绝一切新委托
- **模拟与实盘严格区分**：实盘需用户在页面上单独开启并二次确认；实盘凭据只在交易进程中可用，agent 的工作环境里不存在实盘凭据
- **幂等**：每个委托带客户端生成的唯一 id，断线重连后不重复下单
- **审计日志**：每笔委托记录时间、策略、插件 id 与版本、风控检查结果、券商回执。日志只追加，不修改
- **对账**：定期把平台记录的持仓与券商返回的持仓对比，不一致时停止自动交易并告警
