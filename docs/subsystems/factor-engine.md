# 因子引擎与算子

## 职责

- 平台：调度因子计算、管理缓存、执行契约检查、记录版本
- SDK：提供高性能算子库和可选的表达式解析器，供插件作者选用
- 因子插件：定义因子，决定怎么算

平台**不强制**插件使用表达式或 SDK 算子。插件只需实现 `FactorPlugin.compute`。

## 数据约定

- 输入：长表，每行是一个 (date, symbol)，列为字段（`open`、`close`、`volume` 等），按 (symbol, date) 排序
- 输出：长表，列为 `date`、`symbol`、`value`（Float64）
- 缺失值用 null，不用 0 填充
- 算子的窗口按 **K 线根数**计算，不按自然日。这样日频和分钟级共用同一套算子

## 算子分类（M3）

| 类别 | 例子 | 分组方式 |
|---|---|---|
| 时间序列 | `Ref`、`Mean`、`Std`、`Corr`、`TsRank`、`TsMax`、`Decay`、`Delta` | 按 symbol |
| 横截面 | `Rank`、`ZScore`、`Scale`、`IndNeutralize` | 按 date |
| 逐元素 | `Abs`、`Log`、`Sign`、`If`、`Max`、`Min` | 无 |

算子库按 Alpha191 的需求设计，它是三套内置因子中最复杂的。能覆盖 191，基本就能覆盖绝大多数自定义因子。

## 官方参考插件（M3，放在独立的插件仓库）

| 插件 | 验证方式 |
|---|---|
| Alpha158 | 与 qlib 在同一份数据上逐值对照 |
| Alpha101 | 黄金数据集；原始定义中的歧义逐条记录取舍 |
| Alpha191 | 黄金数据集；原始定义中的歧义逐条记录取舍 |

## 缓存与可复现

- 因子值缓存键：插件 id + 插件版本 + 因子 id + 表达式或代码哈希 + 数据快照 id
- 每次研究和回测记录所用插件版本和数据快照

## 性能

- 全部使用 polars 惰性表达式，多线程执行
- 公共子表达式只算一次
- 全市场日频因子计算的耗时进入 CI 做回归检查（M3）
- 只有在出现性能瓶颈时，才把个别热点算子用 Rust 重写，作为 SDK 的内置算子

## 正确性要求

- 每个因子插件启用前必须通过 `check_no_lookahead`、`check_deterministic`、`check_factor_output`
- 时间序列算子不得跨 symbol 取值；横截面算子不得跨 date 取值
